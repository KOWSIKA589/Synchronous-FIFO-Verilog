# Synchronous FIFO using Verilog

A **Synchronous FIFO (First-In First-Out)** memory design implemented using **Verilog HDL**.

## 📌 Overview

A FIFO is a memory structure in which data is read in the same order in which it was written.

This project implements a synchronous FIFO using a common clock for both read and write operations. The design demonstrates memory organization, read/write pointers, and FIFO status control.

## ⚙️ Features

* First-In First-Out data handling
* Synchronous read and write operations
* Memory array for data storage
* Read pointer
* Write pointer
* Full and empty status indication
* Reset functionality
* Verilog testbench and simulation
